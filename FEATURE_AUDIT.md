# Research Terminal Feature Audit

Audit date: 2026-10-31. This file separates verified behavior from remaining data gaps. A blank metric means the source did not supply enough evidence; it is not estimated.

| Feature | Current behavior | Root cause found | Resolution / remaining limit |
| --- | --- | --- | --- |
| NSE prices | 2,926 published quote rows for 2026-10-30; 2,952 provider rows validated and 26 unknown securities excluded | The retained SQLite archive ended earlier than the generated static snapshot | The UI and API now prefer the validated dated snapshot. Daily workflow validates date, coverage, ISIN uniqueness and OHLCV invariants before publishing. |
| BSE prices | 2,678 published quote rows for 2026-10-30 | BSE was absent from the original refresh and symbol keys collided with NSE | BSE is fetched and validated separately and stored under `BSE:<symbol>`. Search and research links carry the exchange. |
| Security search | 3,392 NSE entries and 2,678 BSE entries in the current combined snapshot | Original search was NSE-only and the local API database does not contain the generated BSE universe | Static search is exchange-aware. BSE instruments remain labelled `UNCLASSIFIED_BSE_SECURITY` because the price provider does not prove their instrument class. |
| Trailing P/E, shares and 52-week range | Current fundamentals snapshot contains 2,945 NSE securities from a named secondary source | Public pages read only a small dossier cache, so most securities displayed blanks despite a broader batch feed | Research, Compare, Watchlist and generated snapshot reports read the batch file. The next fundamentals refresh maps dual-listed BSE facts only through exact ISIN equality and publishes per-exchange coverage. |
| P/B | Displayed only when a dated price, price date, total equity, shares and a balance sheet no more than 12 months old exist | Provider-reported P/B and book value lacked a dated balance-sheet equity input | P/B stays null with a reason. No provider multiple is substituted. Broad P/B coverage still requires dated filing ingestion. |
| Company overview | Displayed only when a source supplied a summary | The old adapter generated a generic sentence when the provider returned no description | Generated prose is removed. Most securities will say that a sourced overview is unavailable until a profile source is ingested. |
| Financial statements | Available only for the limited detailed dossier cache | A quote feed cannot supply audited statement periods, and fetching thousands of per-company statements is a separate rate-limited job | Missing periods remain unavailable. The terminal does not label quote-feed fields as filings. |
| Market capitalization | Latest exchange close multiplied by sourced shares outstanding | API reports could use the older SQLite close while public pages used the newer snapshot | API and static pages now use the same verified exchange close. Market cap remains unavailable if shares are missing. |
| Peer comparison | Uses one set of committed snapshots and positive sourced P/E observations | It previously downloaded snapshots once per peer, attempted direct browser provider calls and inserted unrelated default peers | Snapshot files load once. Unknown sectors receive no invented peer group, and arithmetic discounts are not called a margin of safety. |
| Watchlist | Persists exchange, shows dated close, trailing P/E and P/B availability | It stored only a symbol/name and displayed no market data; NSE and BSE symbols could collide | Rows use exchange-specific quote and fundamental keys. Missing metrics display as unavailable. |
| Reports | Generates a sourced snapshot report for any security in the combined search snapshot | Static hosting only had a short hard-coded list of Markdown reports | The report browser loads the full exchange-aware search index and builds a facts-only report when no detailed report exists. Printing supplies the static PDF path. |
| Data quality page | Reads current status, counts, source hashes and trading dates from committed JSON | It displayed hard-coded counts, truncated hashes and “100% verified” even when the API was absent | Hard-coded fallback figures were removed. Failure to load status is shown as unavailable. |
| Valuation | Runs only from explicit user inputs or reports `NOT_CALCULATED` | Fixed growth, discount-rate and bank-multiple assumptions were previously implicit | The research endpoint does not choose assumptions or manufacture a target price. |
| Industry and risk narrative | Unavailable unless a dated cited source is ingested | Static macro claims and company-specific risk assertions had no evidence record | Production research returns an explicit unavailable reason. Demo lab pages remain visibly marked as synthetic. |

The free sources currently connected do not verify complete company profiles, audited statements or dated book equity for every listed company. Those fields cannot honestly be called complete. The implemented refreshes publish available coverage and failure counts so expansion can be measured without filling gaps with assumptions.
